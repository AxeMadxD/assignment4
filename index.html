Assignment 4. Forms and validation

Akhmad Zhagiparov, group IT-2510. Astana IT University, 2026.

Three forms built with Bootstrap 5.3 components and restyled with my own CSS. There is no JavaScript on any page and no novalidate attribute: every rule is written with HTML attributes, and the browser does the checking.

Task 1

Book a train ticket

A segmented control, floating labels, dates, a select, radio buttons, an input group with +7, a switch and two buttons that swap places on a phone.
Task 2

AITU Hack 2026

Thirteen fields where every rule is an HTML attribute: type, required, min, max, step, minlength and maxlength. Errors appear only after a field is changed.
Task 3

Reserve a table

The café form rebuilt: connected labels, real input types, one radio group, a real button, and everything reachable with the keyboard.
